NEON LOVE HEART — วิธีนำขึ้นเว็บฟรี

ไฟล์หลัก:
- index.html : เว็บไซต์หัวใจนีออนแบบเคลื่อนไหว เปิดได้ทั้งมือถือและคอม
- README.txt : คู่มือฉบับนี้

วิธีดูในเครื่องก่อน:
1. แตกไฟล์ ZIP
2. ดับเบิลคลิก index.html
3. เว็บจะเปิดในเบราว์เซอร์ได้เลย โดยไม่ต้องติดตั้ง Python

วิธีเผยแพร่ฟรีด้วย GitHub Pages:
1. สมัคร/เข้าสู่ระบบ https://github.com
2. กดเครื่องหมาย + มุมขวาบน แล้วเลือก New repository
3. ตั้งชื่อ repository เช่น neon-love-heart
4. เลือก Public แล้วกด Create repository
5. กด Add file > Upload files
6. อัปโหลด index.html (ไม่จำเป็นต้องอัปโหลด README ก็ได้) แล้วกด Commit changes
7. เข้า Settings ของ repository
8. เลือก Pages จากเมนูด้านซ้าย
9. ในส่วน Build and deployment เลือก Deploy from a branch
10. เลือก Branch: main และ Folder: /(root) แล้วกด Save
11. รอสักครู่ แล้วกลับมาหน้า Pages จะมีลิงก์เว็บไซต์ให้ กดเปิดทดสอบ
12. ส่งลิงก์นั้นให้เพื่อนผ่าน LINE, Messenger หรือช่องทางที่ต้องการ

หมายเหตุ:
- GitHub Pages อาจใช้เวลาสักครู่กว่าลิงก์จะพร้อม
- ห้ามส่งรหัสผ่านบัญชี GitHub ให้ใคร
- หากต้องการเปลี่ยนคำว่า “ซีน” ให้เปิด index.html ด้วย Notepad แล้วแก้บรรทัด: const phrase = 'ซีน';
